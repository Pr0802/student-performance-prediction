About This BCA Project

Technical architecture, dataset details, and machine learning methodology.

🎓 Project Information

Project Title: Student Performance Level Prediction Using Machine Learning
Course: Bachelor of Computer Applications (BCA)
ML Algorithm: Decision Tree Classifier (Scikit-learn)
Backend: Python Flask (REST API & Web Server)
Frontend: HTML5, Vanilla CSS3, JavaScript (ES6)
Dataset: StudentsPerformance.csv (1,000 Records)
Model Accuracy: 95.5% on 20% Unseen Test Set

⚙️ How the System Works

  1. Data Collection & Preprocessing: Student demographic data (gender, parental education, lunch, test preparation) and academic marks (math, reading, writing) are gathered from StudentsPerformance.csv.
  2. Feature Encoding: Categorical attributes are mapped to numerical indices for machine learning processing.
  3. Decision Tree Training: The classifier learns hierarchical decision boundaries based on score thresholds and student factors to categorize performance into High, Medium, or Low.
  4. Dual Mode & Fallback: If the trained model file is not available, the website seamlessly defaults to rule-based score calculation, ensuring zero disruption during presentations.
